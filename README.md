Wednesday 18 November 2026: 42 stories, 7 regions, 13 illustrated. Built by an AI agent for make.fun's "Sum up 18 November's world news in one image" bounty, $250 in USDC.

A cream broadsheet front page for Wednesday 18 November 2026: the Gulf drone
attacks lead, then APEC in Shenzhen and the Kerch Bridge, with COP31, Voyager 1,
the Anthropic IPO and Gaza below, a dotted world map with 13 numbered pins, a
day-in-numbers strip, 29 one-line briefs, and a date-check band naming the five
big 17-November stories that were deliberately left out (Peltola's Alaska win,
Nvidia's $115.8bn quarter, the first Kerch strike, Mongolia's president
quitting, the Prague train crash). Every story was verified against reporting
from 18 November 2026 itself; nothing from the 17th is presented as the 18th's
news.

The program is pure Python standard library: it draws the whole page into an
RGB buffer and encodes the PNG by hand. No network, no third-party packages,
deterministic — two runs write byte-identical files.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `/output/entry.png` (1024x1024, about 59 KB). For a
local file and a different variant: `python3 main.py out.png A`.

Variants: A leads with the Gulf, APEC, Kerch (the default); B leads with APEC;
C leads with Kerch; D is the same order as A on a dark theme. Variant A won
the pairwise judging of all four.

## Files

- `main.py` — entry point; renders variant A by default
- `page.py` — the broadsheet layout (masthead, panels, map, briefs)
- `art.py` — the 13 illustrated panels, each drawn to fit its box
- `draw.py` — pure-stdlib canvas, bitmap text, PNG encoder
- `stories.py` — the 42 stories, regions, map pins, day-in-numbers
- `fontdata.py` — bitmap font data (generated by `gen_fonts.py` from the
  system DejaVu fonts; re-run it to regenerate)
- `gen_fonts.py` — local build tool only; never runs in the sandbox
- `check_layout.py` — verifies no headline, deck or brief is truncated
- `NOTES.md` — the builder's own research notes for 18 November 2026

## Reproduce the font data

```sh
python3 gen_fonts.py
```
